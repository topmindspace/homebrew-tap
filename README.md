# Homebrew Tap for topmind

Official Homebrew Cask repository for **[topmind Desktop](https://github.com/topmindspace/topmind)** — Local-first personal knowledge desktop workspace with stream and AI co-pilot.

## Installation

Run the following command in your terminal to install Topmind Desktop on macOS:

```bash
brew install topmindspace/tap/topmind
```

Or tap first, then install:

```bash
brew tap topmindspace/tap
brew install --cask topmind
```

> **Note**: Installing via Homebrew automatically clears the macOS `com.apple.quarantine` attribute upon completion, preventing Gatekeeper from showing the *"App is damaged and can't be opened"* prompt.

## Upgrade

To upgrade Topmind Desktop to the latest version:

```bash
brew upgrade topmind
```

## Uninstall

To uninstall Topmind Desktop and remove associated application support files:

```bash
brew uninstall --zap topmind
```
